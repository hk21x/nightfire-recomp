NightFire's launcher no longer builds the whole game on your PC: it downloads a ready-made package and compiles only
the game's code from your disc. This release also brings 60 FPS driving on the European disc, a new settings window
and more graphics options.

## Getting the game ready, in seconds

Until now the first build downloaded about 1.4 GB of build tools and this project's source, then built for up to 90
minutes. Now the launcher downloads one package (the runtime and a compiler, for both the PAL and the USA disc, with
none of the game's code) and compiles the game's code from your disc into `Nightfire.dll` and `NightfireDriving.dll`.
On a fast PC that took 21 seconds. No Git, no source checkout and no build tools on your PC, so the problems some
players had with those are gone too.

## The driving missions at 60 FPS on the European disc

On the European (PAL) disc, the driving missions ran at 50 frames a second, as they did on a PAL Xbox: the game times
its driving half by the TV standard it finds. They now run at 60, as the USA disc always did, with the game's speed
and timers unchanged. The European disc's own movies and speech are still used. The on-foot missions were already at
60.

## A new settings window, and more graphics options

- The settings window (F1) is redone: a list of sections, full-width rows and a help line for each, and it can be
  used with a controller.
- New graphics options, all off by default: **SMAA**, a **sharp scaling** filter, **alpha edges with MSAA** (smoother
  fences and foliage), **low latency**, and **Enhanced world textures** (sharper world textures; it can cause short
  hitches while new textures load).
- **F12** saves a screenshot of the game as a PNG in a `screenshots` folder beside the game.
- Faster drawing in busy scenes.

## Updating

Open **NightFireLauncher.exe**. It offers this release at the top: press **Update the launcher**. When it has
restarted it offers **A faster way to play**: press **Update**. Your disc choice, saves and settings stay as they are.

New players: download **NightFireLauncher.exe** below, choose your disc and press **Get the game ready**.

## What's in this release

| File | What it is |
|---|---|
| `NightFireLauncher.exe` | **The only file to download by hand.** It fetches the rest itself. |
| `NightFire-package.zip` | The runtime and the compiler, for both discs, and no game code. The launcher fetches it. |
| `NightFire-package.zip.json` | The size and SHA-256 the launcher checks the download against. |

No game files are included. You need your own copy of the game (the European PAL or the USA release). See the
[v1.0.0 notes](https://github.com/hk21x/nightfire-recomp/releases/tag/v1.0.0) for everything in the port.

Help and reports: the [Discord server](https://discord.gg/PQjkKsdtc). Problems: the game's log is in
`NightFire\play\logs`, the launcher's in `NightFire\launcher.log`.
